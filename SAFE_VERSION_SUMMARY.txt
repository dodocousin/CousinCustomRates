## HOW IT WORKS

### The Safe Retry Logic:

```cpp
1. Player joins server
   ↓
2. PostLogin hook calls GetAndCacheTribeMemberCount()
   ↓
3. Check IsInTribe():
   - false → return 1 (solo player)
   - true → continue
   ↓
4. Read MyTribeDataField().MembersPlayerDataIDSet_ServerField().Num()
   - > 0 → Cache and return (SUCCESS!)
   - = 0 → Return 0 (not loaded yet)
   ↓
5. If returned 0:
   - TribeSizeMultiplier won\'t apply yet
   - Timer calls function again in 60 seconds
   - OR player opens tribe UI (loads data immediately)
   - Next call will succeed
```
